# Bibliografía candidata — PYDEV-001

Este archivo centraliza fuentes candidatas para la preparación de clases. Los títulos señalados como procedentes de *Awesome Python Books* se transcriben del catálogo enlazado; ese catálogo ayuda a descubrir libros, pero no valida su uso curricular.

**Regla de verificación:** antes de asignar una lectura, confirmar el ejemplar disponible, idioma, edición, editorial/año cuando sean identificables, índice/tabla de contenido y correspondencia con la clase. Mientras falte esa verificación, la referencia es una propuesta; capítulos y páginas quedan sin asignar.

Fuente de descubrimiento: [junnplus/awesome-python-books](https://github.com/junnplus/awesome-python-books).
