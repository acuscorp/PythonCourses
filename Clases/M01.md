# 6. Clases

## Clase 1 — Nombres, objetos, asignación e identidad

### Objetivos

- Entender que un nombre se vincula a un objeto.
- Distinguir reasignación de mutación.
- Predecir cuándo dos nombres se refieren al mismo objeto.
- Diferenciar igualdad e identidad.

### Explicación

`x = 10` vincula el nombre `x` con un objeto entero. Después, `x = 20` vuelve a vincular el nombre; no transforma el objeto entero `10`.

Si dos nombres se refieren al mismo objeto mutable, una mutación de ese objeto puede observarse a través de ambos nombres: esto se denomina *aliasing*.

`==` comprueba igualdad según la operación de comparación del tipo. `is` comprueba identidad: si se trata del mismo objeto. No uses `is` como sustituto general de `==`. Un caso habitual de identidad es `value is None`.

### Ejemplo

```python
first = [1, 2]
second = first
second.append(3)

print(first)
print(second)
print(first is second)
print(first == second)
```

Salida:

```text
[1, 2, 3]
[1, 2, 3]
True
True
```

La asignación `second = first` no crea otra lista; ambos nombres se refieren al mismo objeto.

Contraste:

```python
x = 10
y = x
x = 20
print(x, y)
```

Salida:

```text
20 10
```

La reasignación de `x` no cambia el vínculo de `y`.

### Ejercicios

1. Antes de ejecutar el primer ejemplo, predice cada salida y explica por qué.
2. Cambia una sola línea y vuelve a predecir.
3. Resuelve un caso nuevo que combine aliasing y reasignación.
4. Explica si cambió el objeto, el vínculo de un nombre o ambos.

**Criterio de salida:** explicar correctamente un caso nuevo de aliasing y otro de reasignación, distinguiendo identidad e igualdad.

## Clase 3 — Condicionales y bucles

### Objetivos

- Escribir condiciones con `if`, `elif` y `else`.
- Trazar un `for` o `while` paso a paso.
- Comprender que el límite final de `range` no se incluye.
- Explicar `break` y `continue`.

### Explicación

`if` selecciona una rama. `for` recorre elementos; en esta clase se trabajará principalmente con `range` y cadenas. `while` repite mientras su condición sea verdadera.

`range(start, stop, step)` produce enteros desde `start` y se detiene antes de `stop`. `break` termina el bucle más cercano; `continue` pasa a la siguiente iteración.

### Ejemplo

```python
total = 0

for number in range(1, 5):
    if number == 3:
        continue
    total += number

print(total)
```

Salida: `7`, porque se suman `1`, `2` y `4`.

### Ejercicios

1. Traza los valores de las variables en cada iteración.
2. Cambia los límites de `range` y predice cuántas iteraciones ocurren.
3. Resuelve un problema breve con una condición y un acumulador numérico.
4. Encuentra y corrige un `while` que no termina.
5. Explica un caso límite.

**Criterio de salida:** resolver una variante nueva con condición y bucle, y explicar sus casos límite.

## Clase 4 — Cadenas, f-strings, slicing y excepciones

### Objetivos

- Construir cadenas con f-strings.
- Usar operaciones básicas, índices y slicing.
- Entender que las cadenas son inmutables.
- Capturar una excepción esperable de forma específica.

### Ejemplo de cadenas

```python
text = "Python"
print(text[0])
print(text[-1])
print(text[1:4])
print(f"Lenguaje: {text}")
```

Salida:

```text
P
n
yth
Lenguaje: Python
```

El slice incluye el inicio y excluye el límite final. Las cadenas no se modifican por índice; para cambiar el contenido se construye otra cadena.

### Ejemplo de excepción

```python
raw_value = "abc"

try:
    number = int(raw_value)
except ValueError:
    print("La entrada debe ser un entero.")
else:
    print(number)
```

Salida:

```text
La entrada debe ser un entero.
```

`except ValueError` captura el error esperado de conversión. `else` se ejecuta si no hubo excepción en el bloque `try`.

### Ejercicios

1. Predice índices y slices, incluidos los límites.
2. Corrige un intento de modificar una cadena por índice.
3. Formatea una salida con f-string.
4. Maneja `ValueError` sin ocultar otros errores.
5. Explica qué bloque se ejecuta cuando ocurre la excepción.

**Criterio de salida:** transformar una cadena en memoria y manejar una entrada inválida explícitamente.

## Clase 5 — Imports y punto de entrada

### Objetivos

- Distinguir `import math` de `from math import sqrt`.
- Entender que las instrucciones de nivel superior se ejecutan al importar un módulo.
- Usar `if __name__ == "__main__":`.

### Ejemplo

Archivo `geometry_demo.py`:

```python
import math

def circle_area(radius):
    return math.pi * radius ** 2

if __name__ == "__main__":
    print(circle_area(2))
```

Al ejecutar el archivo como programa se imprime el área. Al importarlo, se define `circle_area` sin ejecutar ese `print`.

Con `import math`, se usa `math.sqrt(9)`. El nombre `sqrt` no se incorpora directamente al espacio de nombres. Para usarlo directamente habría que ejecutar `from math import sqrt`.

No se estudian ciclos de importación ni diseño avanzado de paquetes; corresponden a módulos posteriores.

### Ejercicios

1. Predice qué nombres están disponibles tras cada forma de importación.
2. Explica por qué `sqrt(9)` no funciona después de `import math`, mientras `math.sqrt(9)` sí.
3. Detecta el efecto secundario de un `print` al nivel superior de un módulo.
4. Separa la lógica de una demostración ejecutable.

**Criterio de salida:** crear un módulo que se pueda importar sin ejecutar la demostración.

## Clase 6 — Primeras pruebas con `unittest`

### Objetivos

- Entender una prueba como una comprobación de comportamiento.
- Escribir pruebas sencillas con `unittest`.
- Observar un fallo, corregir el defecto y explicar la corrección.

Archivo `text_tools.py`:

```python
def normalize_spaces(text):
    return " ".join(text.split())
```

Archivo `test_text_tools.py`:

```python
import unittest
from text_tools import normalize_spaces


class NormalizeSpacesTests(unittest.TestCase):
    def test_collapses_repeated_spaces(self):
        self.assertEqual(normalize_spaces("hola   mundo"), "hola mundo")

    def test_handles_leading_and_trailing_spaces(self):
        self.assertEqual(normalize_spaces("  hola mundo  "), "hola mundo")


if __name__ == "__main__":
    unittest.main()
```

Ejecuta:

```bash
python -m unittest -v
```

Las pruebas comprueban comportamiento observable. No se estudian todavía cobertura, mocks, pruebas de integración ni CI. En esta clase se elige `unittest` como único framework inicial.

3. Corrige el defecto y vuelve a ejecutar.
