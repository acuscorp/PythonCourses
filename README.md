# PYDEV-001 — Python para desarrolladores

Repositorio curricular del curso de Python para desarrolladores.

## Archivo curricular activo

- [Ruta curricular](LEARNING_PATH.md).
- [Estado del curso](COURSE_STATE.md) — posición actual y progreso académico registrado.

## Estructura del repositorio

- `Clases/MXX - Nombre del módulo/`: carpeta de cada módulo, nombrada con su ID y título de la ruta; contiene un `README.md` de módulo y materiales de clase `MXX-CNN - Título de la ruta.md`.
- `LEARNING_PATH.md` reúne propósito, jerarquía, resultados y prerrequisitos por módulo, instrucciones y límites de generación, e índice de clases con alcance, evidencia y lecturas.
- [Matriz de competencias](MATRIZ_COMPETENCIAS.md): borrador para revisión.

## Reglas de mantenimiento

- No sobrescribir un archivo existente sin leerlo primero y confirmar que corresponde actualizarlo.
- Conservar la ruta curricular activa en los cambios administrativos.
- No marcar una clase como completada ni una competencia como validada sin evidencia.
- No publicar contraseñas, tokens, claves API, archivos de entorno, datos médicos, datos personales sensibles ni evidencias identificables.
- Mantener los borradores claramente separados de los materiales aprobados.
