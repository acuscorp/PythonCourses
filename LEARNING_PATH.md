# Ruta curricular — Python para desarrolladores

## Propósito y organización

Esta ruta define las competencias, dependencias, alcances y lecturas que orientan la preparación progresiva de las clases. Aprovecha la experiencia previa en Java, Kotlin, Go y C++; los fundamentos generales se revisan solo si el diagnóstico detecta una brecha.

La jerarquía es **Módulo → Submódulo opcional → Clase**. Los submódulos agrupan clases cuando aportan claridad. Ejercicios, actividades y secciones forman parte de una clase; no son niveles curriculares adicionales. Cada clase conserva el ID y título de este índice.

## Instrucciones para generar una clase

1. Cargar `COURSE_STATE.md` y esta ruta; identificar la siguiente clase pertinente, su ID, título, prerrequisitos, objetivo, alcance y evidencia.
2. Preparar clases progresivamente cuando el avance las requiera. Una entrada en esta ruta significa que la clase está planificada, no que su material ya exista, esté completo o esté aprobado.
3. Revisar las fuentes y capítulos de la fila: confirmar la edición y el índice, leer la sección pertinente y contrastar con documentación oficial vigente cuando aplique. Si la edición enlazada no coincide con el ejemplar disponible, localizar y registrar la sección equivalente. Usar solo fuentes realmente consultadas; no inventar capítulos, páginas, citas ni resultados. Si no se puede acceder o verificar una fuente esencial, dejar constancia y no afirmar contenido que no se haya comprobado.
4. Crear el material en estado `DRAFT` y seguir la [Guía para preparar las clases](GUIA_DE_CLASES.md) para su estructura y secuencia didáctica.
5. Antes de marcar `READY`, verificar objetivo observable, prerrequisitos, alcance, explicación y ejemplos, comprobación de comprensión, práctica pertinente, evidencia revisable, errores previsibles con remediación y referencias verificadas. Justificar las excepciones en el propio material.
6. Si falta un artefacto necesario o hay una incompatibilidad con la ruta, detener la generación oficial y reportar el problema; no improvisar un cambio curricular.

## Alcance y límites curriculares

- El alcance y la evidencia de cada clase se indican en el índice detallado. El material puede añadir ejemplos y actividades, pero no contradecir ese alcance.
- No enseñar en profundidad conceptos reservados para módulos posteriores. Se permiten menciones o ejemplos mínimos para aclarar el objetivo actual.
- Como regla, una clase hereda los prerrequisitos del módulo y presupone las clases anteriores del mismo submódulo; declarar excepciones y dependencias cruzadas en el material.
- Los temas exploratorios u opcionales no se vuelven requisitos de aprobación por aparecer en una fuente o actividad.
- Las lecturas propuestas orientan la preparación; no exigen leer un libro completo ni sustituyen la evidencia de aprendizaje.
- Leer o generar una clase no valida por sí mismo una competencia del estudiante. La validación requiere la evidencia prevista y su registro en el estado del curso.
